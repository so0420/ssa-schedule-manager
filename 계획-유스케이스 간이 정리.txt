팀 프로젝트 일정 관리 프로그램 (웹페이지)
사용 언어: Java
유의:
	- 백엔드 구조는 최대한 단순하게 해서 개발자가 모든 구조를 꿰고 있을 수 있도록. UML 작성 용이하게 + 구조 질문받을 때 답변 쉽게
	- StarUML로 유즈케이스 다이어그램도 그려두기. 이 경우 "D:\전북대\소프트웨어시스템분석및설계" 참고하여 배우지 않은 표기법은 사용하지 않기. (가능한 한 기본 표기법으로만)

A. 계정 관리
A1. 회원가입
	A2. 개인정보 수정
		A2-1. 사용자명 변경
		A2-2. 비밀번호 변경
	A3. 로그인
		A3-1. 로그인
		A3-2. id 찾기
		A3-3. 비밀번호 찾기
	A4. 로그아웃
	A5. 회원 탈퇴

B. 서비스
	B1. 관리자 문의(기능구현이라기보단 푸터에 메일 등 연락처 제공 정도로만 간단히)
	B2. 이용약관 열람
	B3. 개인정보처리방침 열람

C. 일정
	C1. 일정 등록
		C1-1. 일정명, 내용 혹은 메모, 일정 시점 입력
		C1-2. 일정에 연관된 유저 태그 입력
	C2. 일정 조회
		C2-1. 다가오는 일정 조회 (ex: 1주일 내 예정된 일정 조회)
		C2-2. 일정 필터 및 검색
	C3. 일정 수정
		C3-1. 일정명, 내용 혹은 메모, 일정 시점 수정
		C3-2. 일정에 연관된 유저 태그 수정
	C4. 일정 삭제
	C5. 일정 완료
		C5-1. 시간 지남에 따른 자동 완료
		C5-2. 수동 완료 상태 변경

D. 알림
	D1. 알림 켜기/끄기
	D2. 외부 알림 연동
	D3. 외부 알림 연동해제

E. 어드민
	E1. 멤버 관리
		E1-1. 멤버 회원가입 승인 및 거절 (승인제로 갈 경우)
		E1-2. 멤버 추방
	E2. 로그 열람
